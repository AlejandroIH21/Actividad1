# Máquina Expendedora

Programa de consola en C# que simula una máquina expendedora de bebidas y bollería (Variante G: Café, Infusión y Magdalena), permitiendo comprar productos, reponer stock y consultar un informe de ventas.

## Requisitos

- SDK de .NET 10

## Cómo se ejecuta

```bash
dotnet run --project Expendedora
